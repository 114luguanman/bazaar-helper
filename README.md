# 🐳 大巴扎小帮手 (The Bazaar Helper)

> 专为《The Bazaar（大巴扎）》萌新打造的**本地辅助软件**：打开游戏挂机就行，它会**自动看懂你买了什么**，告诉你**该往什么流派发展、哪件道具是当前流派的核心、缺什么去哪个商店买、怎么摆放**——让第一次玩的你也能轻松组出有强度的阵容。

## ✨ 它能帮你做什么？

### 🎯 一句话版
> 你玩游戏，它帮你思考。屏幕识别你的物品 → 匹配最强流派 → 告诉你下一步怎么走。

### 📖 萌新版（详细说明）

**1. 看不懂流派？→ 它直接告诉你答案**
- 自动识别你棋盘/背包上的所有物品（**读取游戏日志，100% 准确**，不会看错）
- 根据你已有的东西，匹配**最适合你的流派**（攻略来自 [bazaar-builds.net](https://bazaar-builds.net) 的实战高分阵容 + [巴扎丘Bot](https://bazaarqiubot.com) 的天梯统计组合，覆盖 **8 位英雄含新角色"双龙"**、数千套流派）
- 显示：**还差哪些核心件**（带中文效果介绍 + CD 时长）、**该去哪个商店买**（含优先级）、**哪些物品建议替换**、**技能野怪推荐**

**2. 不知道哪些道具强力？→ 推荐里有答案**
- 每个推荐物品都附上**中文效果说明和冷却时长**（如：`悠悠球（CD 4秒 · 造成1伤害；使用相邻物品时充能4秒）`），一眼看懂这件东西强在哪
- 缺失件按**稀有度从低到高**排序（Bronze→Diamond，萌新更好入手），**本英雄专属物品优先**，其他英雄的物品自动降权并标注"慎选"

**3. 会玩流派但不会摆？→ 摆放指导**
- 告诉每件组件**该放棋盘哪个位置**（如"补「小圆猪守卫」→ 放 2号位（上中左）"），自动避开已占用格位
- 核心件居中、相邻增益件贴邻、武器护盾对角——攻守循环摆位建议
- 如果觉得 AI 给的建议太抽象，也可以在控制面板的**推荐流派**处找到您当前追踪的流派，查看这套阵容的主人最终是如何摆放的

**4. 想自由搭配？→ 流派搜索 + 自选**
- **搜索功能**：输入物品名（中/英都行，如"悠悠球"或"yoyo"）→ 弹出**覆盖率最高的前 3 个流派候选**（便利贴形式）→ 点击选择
- **锁定流派**：选定后桌宠**持续按该流派给建议**，不会再被自动推荐覆盖；随时可"解除锁定"回到自动推荐

**5. 开黑累了？→ DeepSeek娘桌宠陪你**
- 内置 **DeepSeek娘·蓝发鲸鱼女仆** 和 **像素鲸鱼娘** 两套桌宠形象（16-18 FPS 流畅动画：登场挥手/说话/指点/待机眨眼）
- 点击桌宠弹出**完整功能菜单**（浓缩了控制面板全部功能），可换形象、可说话、会"指出"屏幕上的物品
- **建议便利贴**：深蓝半透明卡片常驻屏幕，可拖动、可缩放、随时显示当前推荐
- 以上动画素材均来自开源社区的成品形象；**至于桌宠动画的制作，本人实在一窍不通，制作纰漏太多，难以做出不"难绷"的动画，还请大家见谅。** 🙏

## 🚀 快速开始

### 安装

需要 **Python 3.10+（Windows）**，双击运行即可（依赖已打包在本地 vendor/，通常无需安装）：

```
双击「启动大巴扎小帮手.bat」
或双击桌面快捷方式「大巴扎小帮手」（推荐，无黑框）
```

命令行方式：

```powershell
cd D:\巴扎小帮手
python run_app.py        # 自动检测并安装缺失依赖
```

> 首次启动会自动生成示例桌宠并加载缓存攻略；到「数据」页点"更新"可拉取最新流派数据。

### 三步上手

1. **打开游戏**（建议"无边框窗口化"，这样悬浮窗能盖在游戏上）
2. **点击桌宠** → 监视 → **开始监视**（它开始自动读取你的游戏日志）
3. **看建议**：桌宠气泡/便利贴会告诉你当前最优流派和下一步行动

## 🎮 核心玩法详解

### 自动识别（日志驱动，100% 准确）
程序直接读取游戏的 `Player.log`（Unity 日志），**每张卡的购买、移动、交换、出售都被精确追踪**——不会把对手的卡认成你的，也不会漏掉你的事件奖励卡。识别结果实时显示在面板，双击某物品桌宠会飞过去指出它。

### 流派推荐（数据驱动）
- **数据源**：
  - [bazaar-builds.net](https://bazaar-builds.net)（WordPress API）实战高分流派
  - **[巴扎丘Bot](https://bazaarqiubot.com)（天梯统计，权重更高）**：基于真实天梯对局自动归类的**核心组合 → 变体 → 完整配置**，含出现率与 10 胜率；支持**双龙(The Dragons)**新角色；还能查询目标卡最常搭配的卡
- **英雄**：Mak / Vanessa / Dooley / Pygmalien / Stelle / Jules / Karnok / **双龙(The Dragons)**
- **匹配逻辑**：**优先推荐整个流派**（完整卡组阵容，非零散物品搭配）；你拥有的组件越多 → 流派排名越靠前；缺失件优先本英雄、低稀有度；**其他英雄专属物品自动降权**（拿不到的流派不会推荐给你）
- **英雄自动识别**：日志检测到你换了英雄 → 自动切换攻略库 + 自动更新数据 + 立即重新推荐

### 物品搭配分析（独立页签）
想研究"某件物品该配什么"？在「搭配分析」页输入物品名（如：齿轮 / Cog / 悠悠球）：
- **🤝 最常一同使用的卡**（按天梯共同出现率排序）
- **🏆 一同使用 10 连胜概率最高的卡**（含胜率与局数）
- 数据来自巴扎丘Bot 数万场天梯对局统计，热门物品一键速查

### 桌宠菜单（浓缩控制面板）
| 菜单 | 功能 |
| --- | --- |
| 监视 | 开始/停止监视、识别间隔、识别结果列表（点击指认）、卡牌校准、导出诊断、保存截图 |
| 推荐 | 切换英雄、立即分析、**流派搜索**、建议便利贴开关、桌宠讲解、替换建议 |
| 搭配分析 | **物品搭配查询**：最常一同使用的卡 + 10连胜概率 |
| 桌宠 | 静态/动画模式、图标大小、选择/上传形象、测试动画、说话 |
| 数据更新 | 更新物品图鉴、更新流派攻略、**更新天梯组合（巴扎丘Bot）** |
| 设置 | 自动建议、鼠标穿透、建议阈值 |
| 💖 | **支持作者**（跳转B站充电） |

### 🐉 巴扎丘Bot（bazaarqiubot.com）—— 天梯统计主力来源

- **单卡到组合的联合查询**：输入目标卡，能查到它**最常一同使用的卡**，以及**一同使用 10 连胜概率最高**的搭配
- **按共同阵容自动归类打法**：从数万场天梯对局中自动提取**核心组合层**（如杜利的「光纤+氮气罐」出现率 11.5%），每个核心组合下还有**不同变体配置**及各自出现率/10 胜率
- **覆盖新角色"双龙"(The Dragons)**：包含双龙的卡牌与组合信息（如「超级粉丝+连帽衫」核心组合出现率 26.5%）
- **社区问答**：内置玩家社区，解答《大巴扎》冷知识（`/trivia` 板块）

**权重策略**：推荐排序中，巴扎丘Bot 的真实天梯统计组合**优先于攻略站投稿**——同一覆盖度下，天梯出现率越高的组合排名越靠前，让你优先看到经实战验证的强势打法。

## ❓ 常见问题

- **识别不准？** 识别以游戏日志为准（100%），日志缺失时（如事件奖励卡）可先**卡牌校准**：面板"卡牌校准"逐张点击棋盘卡 → 保存位置；或"框选棋盘区域"启用视觉补充。
- **悬浮窗被游戏挡住？** 游戏必须用"无边框窗口化"，独占全屏无法悬浮。
- **建议不稳定？** 已修复：日志中文名→英文 key 归一化，覆盖率计算准确；自动建议带冷却防刷屏。
- **想要其他英雄攻略？** 「数据」页"更新流派攻略"会自动拉取当前英雄全部流派；"更新天梯组合（巴扎丘Bot）"会刷新天梯统计（含新角色双龙）；切换英雄后也会自动更新。
